Chat backup

Back up selected Picode chats and their organization metadata. Project files and account credentials are never included.

Compressed context package

Create a small, lossy briefing from selected chats using the model currently selected in the chat window. Nothing is sent until you review and confirm the sources and destination model.

    Confirming will send cleaned conversation text to the selected provider. Known credential fields and token-like lines are removed, but secrets embedded in ordinary prose cannot be detected perfectly. Raw chats are not stored in the output package.
    Warning: an unencrypted package exposes its briefing and structured memories.

# Derive the new product from upstream Picot

Start with a new repository and Git history, but build the product as a derivative of upstream Picot rather than as a clean-room rewrite. We may copy and refactor useful MIT-licensed Picot code while preserving its copyright and license notices; the earlier C# implementation is a behavioral reference, not the technical foundation. This retains mature Pi integration and interface behavior while giving the performance-focused product a clean project boundary.

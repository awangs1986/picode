# Separate Simple Tasks from Harness Tasks

Offer an immediate Simple Task with no user workspace or Harness requirement and a workspace-bound Harness Task instantiated from Picode's built-in, overridable Harness template plus any optional project Harness Profile, so small personal work pays only for Pi's core experience while large projects can choose stronger coordination and evidence. Explicit user commands and invoked Skills may override a Task Harness at task scope, including its Git and verification strategy, while the underlying tool and API layer remains responsible for capability limits and destructive-operation enforcement; this supersedes ADR-0018, ADR-0020, and ADR-0024 as universal policies.

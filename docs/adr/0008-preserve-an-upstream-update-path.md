# Preserve an upstream Picot update path

Maintain Upstream Picot as a continuing source of fixes and features rather than treating the initial code as a frozen snapshot. Keep Picot Next's localization, account vault, chat-control boundary, and performance work in isolated modules wherever practical, minimizing invasive edits to upstream core files. Upstream updates will be reviewed and merged periodically, with conflicts resolved deliberately rather than promising automatic compatibility.

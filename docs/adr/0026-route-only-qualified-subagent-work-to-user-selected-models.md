# Route only qualified Subagent work to user-selected models

Let users configure eligible Subagent models, but treat those models as candidates only after Picode records Delegation Eligibility for a simple, bounded, independent, low-risk, and verifiable unit of work. This rejects both always inheriting the main model and blindly choosing the cheapest model: complex reasoning, writes, architecture, ambiguous work, and work requiring broad shared context stay with the main Agent or an explicitly chosen capable Agent, while unavailable candidates follow the user's declared fallback instead of silently selecting an arbitrary model.
